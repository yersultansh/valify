    Предлагаемое применение

    Как инструмент может использоваться банками

    1. Характеристики объекта

      Кредитный специалист вводит параметры квартиры, предлагаемой в обеспечение кредита.

    2. Предварительный ориентир

      Приложение оценивает цену предложения на основе доступных рыночных данных.

    3. Сравнение с рынком

      Сотрудник получает ориентировочный диапазон, районную медиану и сопоставимые объявления.

    4. Дальнейшая проверка

      Результат помогает при предварительном рассмотрении объекта и определении необходимости дополнительной проверки.

    Предлагаемый сценарий использования: интеграция с банками не реализована. Приложение не принимает решений об одобрении кредита.

    Границы применения

    VALIFY — аналитический инструмент предварительной оценки. Прогноз строится на ценах объявлений, которые могут отличаться от фактических цен сделок. Результат не является официальным отчётом об оценке недвижимости, не устанавливает стоимость залога и не заменяет профессиональную оценку и процедуры банка.
